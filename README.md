# QWERTIS

**QWERTIS** is a falling-letters typing game that can run in a Data URL. It combines falling-block puzzle mechanics with touch typing practice.

## 🤖 Made with Gemini

This game was entirely designed and coded using **Gemini 3 Pro**.

## 🎮 How to Play

Type the words to turn the falling blocks **GREEN**.
*   **Green Blocks** settle on the grid.
*   **Complete a horizontal row** of green blocks to clear it and score points (+10).
*   **Mistakes** cause the block to drop instantly!
*   **Don't let the stack reach the top!**

### Controls
*   **Typing**: Matches the letters on screen (Case-sensitive!).
*   **Arrows**: Move blocks left/right/down.
*   **Space**: Rotate (Only works for 5-letter words).
*   **Enter**: Fast drop.

## 📦 Tiny Footprint

The entire game is self-contained in a single **Data URL**.
*   **Size**: ~38KB

You can play it by pasting the generated Data URL directly into your browser's address bar, or by using the `launcher.html` wrapper.
